# Visual References

Before changing Bewora design, inspect:

- `/public/brand/bewora-logo-reference.png`
- `/public/references/bewora-platform-mockup.png`

## Platform mock-up
Treat the platform mock-up as a visual reference for:
- layout
- spacing
- card proportions
- photo usage
- sidebar/navigation
- dashboard density
- overall premium/calm feeling

Do not copy rendering mistakes or artifacts.

## Logo reference
Treat the logo reference as a starting point only.

The logo must be refined according to the updated brand:

- Archive Green `#1D3D2A`
- less botanical / leaf-like
- retain a recognisable B
- inner forms should suggest pages, archive layers, open book or preserved memories
- simple enough for favicon/app icon use

## Priority rule
Where an image conflicts with the written design specification:
**the written design specification wins.**
